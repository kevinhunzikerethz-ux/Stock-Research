# Stock Research Terminal

A personal stock research and financial analysis terminal focused on
long-term investing and fundamental valuation.

## Planned Features

- Historical stock price data
- Financial statements and key financial metrics
- Revenue, earnings, and free cash flow analysis
- Valuation analysis using historical earnings and P/E multiples
- SQLite database for persistent financial data storage
- Data collection from Yahoo Finance and SEC filings

## Technology

- Python
- SQLite
- yfinance
- SEC Company Facts API
